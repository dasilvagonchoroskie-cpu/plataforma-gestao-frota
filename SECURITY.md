# Segurança

Achou uma falha de segurança na Plataforma de Gestão de Frota? **Não abra issue pública.** Use
"Report a vulnerability" ("Relatar uma vulnerabilidade") na aba Security deste repositório, ou escreva
para gestaodefrota2027@gmail.com. Respondemos em até 5 dias úteis.

Nunca envie senhas, chaves ou dados pessoais de terceiros no relato. Testes só com autorização por escrito
e sem tocar em dados de empresas reais.
